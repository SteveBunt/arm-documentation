# Template Guide

This bundle contains ready-to-edit template files for the core documentation
most open source repositories need. Drop the whole folder structure into the
root of your repository and edit the bracketed placeholders (e.g.
`[Project Name]`, `[INSERT CONTACT EMAIL]`).

## What's included

**Compulsory**
- `README.md`
- `LICENSE` (MIT — swap for another license's text if you want something
  else; see [choosealicense.com](https://choosealicense.com))
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md` (Contributor Covenant v2.1)

**Strongly recommended**
- `CHANGELOG.md` (Keep a Changelog format)
- `SECURITY.md`
- `SUPPORT.md`
- `CODEOWNERS`
- `.github/ISSUE_TEMPLATE/bug_report.md`
- `.github/ISSUE_TEMPLATE/feature_request.md`
- `.github/ISSUE_TEMPLATE/config.yml`
- `.github/PULL_REQUEST_TEMPLATE.md`

**Optional (included as a starting point)**
- `GOVERNANCE.md`
- `ROADMAP.md`
- `.github/FUNDING.yml` — delete this file entirely if you're not accepting
  sponsorship, otherwise GitHub will show a broken "Sponsor" button

## Notes

- Anything in `[square brackets]` or marked `USERNAME`/`REPO`/`YEAR` needs
  editing before these are useful.
- `GOVERNANCE.md` and `ROADMAP.md` are only worth keeping once you have more
  than one maintainer or an active user base — delete them for a small solo
  project and add them back later.
- If you want templates for the more advanced/optional docs too (e.g.
  ARCHITECTURE.md, GLOSSARY.md, CITATION.cff, TRADEMARK.md), just ask and
  I'll generate those as well.
