## Adding a new language

1. Copy the source-language file/folder as a starting point.
2. Translate the content — keep placeholders, code blocks, and links
   unchanged.
3. Add your language to [the list below / the language switcher / the
   config file].
4. Open a pull request. A native speaker will review for accuracy where
   possible.
